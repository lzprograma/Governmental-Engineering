Registrar cidadão

O identificador do modelo é o nome técnico fornecido pelo provedor.

Alguns provedores não publicam catálogo; nesses casos, informe o ID manualmente.
Esta instrução acompanha cada chamada enviada ao provedor. Não conceda privilégios administrativos por meio dela.
A criação não testa nem cobra a API; use o botão de teste na conexão.

Central de conexões API

Cadastre provedores oficiais, gateways, endpoints próprios ou modelos locais.

Segurança: insira chaves apenas neste painel local. O painel cifra as credenciais no disco, mas a segurança completa também depende do usuário e do computador. Não exponha o servidor à internet.
